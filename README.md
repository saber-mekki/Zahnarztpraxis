## 📄 Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage — Hero, Leistungen, Praxis, Philosophie, Bewertungen, Kontakt |

| `datenschutz.html` | Privacy policy (Datenschutzerklärung) |

## ✅ Features

- Fully responsive (desktop, tablet, mobile)
- No JavaScript framework — pure HTML/CSS
- Fast loading, no dependencies

## 🏗️ Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Google Fonts (DM Serif Display, Inter)
- Google Maps Embed
